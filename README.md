## what it is

prompt portal is a free library of ready-to-copy test prompts that creators use to try out new ai models and share the results.

every time a new model drops, creators need good prompts to test it with. this is that list, plus a record of how each model did.

## what's inside

- **5 test types**: game, frontend, animation, blender, architecture
- **difficulty levels** from 1 to 3 on every test
- **one-tap copy** on every prompt
- **a page for each prompt** with past results from different models, including videos and links to the full output
- **live demo window** on the homepage that types out a prompt and shows model scores
- **sun and moon mode** with a smooth crossfade, and it remembers your choice
- **works on phones**, tablets and desktops

## how to use it

1. pick a test from the library
2. tap **copy prompt**
3. paste it into the model you want to test
4. post your result and share the site under your post 🙏

want your result featured? tag [@haleeeemahh](https://x.com/haleeeemahh) on x.
